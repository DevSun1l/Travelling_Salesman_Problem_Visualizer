Theory & NP-Completeness (CLO-5)

The Traveling Salesman Problem (TSP) asks: "Given a list of cities and the distances between each pair of cities, what is the shortest possible route that visits each city exactly once and returns to the origin city?"

Proof of NP-Completeness

1. TSP is in NP: Given a proposed tour (a certificate) and a distance B, a verifier can sum the weights of the edges in the tour and check if the sum is ≤ B in polynomial time O(n).

2. NP-Hardness (Reduction from Hamiltonian Cycle):
Let G = (V, E) be an instance of the Hamiltonian Cycle (HC) problem. We construct a TSP instance G' = (V, E') as follows:

  • Create a complete graph G' with the same vertices V.
  • For every edge in G, assign a weight of 1 in G'.
  • For every edge NOT in G, assign a weight of 2 in G'.

Forward Proof: If G has a Hamiltonian Cycle, the same cycle in G' uses only edges of weight 1. Since a cycle visits all n vertices, its total weight is exactly n. Thus, TSP has a tour of weight ≤ n.

Backward Proof: If TSP has a tour of weight ≤ n in G', it must use exactly n edges. Since the minimum edge weight is 1, it must use only edges of weight 1. These edges correspond precisely to the edges that exist in G. Therefore, G has a Hamiltonian Cycle.
